물리 시뮬레이션, 성능 최적화, 시스템 연동을 중심으로 프로젝트를 진행해 온 엔지니어입니다.  
현상을 구현하는 데서 그치지 않고, 병목을 분석하고 결과를 검증 가능한 형태로 정리하는 작업을 중요하게 생각합니다.

### 중심 분야

- **물리 시뮬레이션**: MPM 기반 시뮬레이터 설계, GPU 커널 구현, 수치 검증
- **성능 분석 / 최적화**: 커널 병목 분석, 모바일 추론 파이프라인 분석, 프로파일링 기반 개선
- **시스템 연동 / 상호작용**: Unity 기반 상호작용, VR 입력 연동, 시뮬레이션 데이터 연결

### 주요 내용

- **과립체 분리 시뮬레이션 구현**: MPM 기반 시뮬레이터를 구현하고 수치 안정성과 시각화 흐름을 정리했습니다.
- **커널 최적화 13% 개선**: 병목 커널을 분석하고 atomic 연산과 메모리 접근 구조를 조정했습니다.
- **모바일 추론 파이프라인 분석**: YOLO 기반 객체 인식 구조를 점검하고 후처리 병목을 확인했습니다.
- **협업형 시스템 구축 경험**: 이미지 편집 파이프라인, VR 상호작용, 시뮬레이션 데이터 연동 프로젝트를 수행했습니다.
