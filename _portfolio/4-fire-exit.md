### 개요

화재 상황에서의 대피 장면을 3차원 환경에서 시각화한 프로젝트입니다. FDS 기반 화재 시뮬레이션 결과와 공간 정보, 객체 좌표 데이터를 연결해 실제 공간에 가까운 대피 시뮬레이션을 구현했습니다.

### 문제

- FDS 결과를 바로 활용하기 어려워 전처리와 연동 구조가 필요했습니다.
- 시뮬레이션 데이터와 공간 좌표가 서로 다른 형식이라 변환 과정이 필요했습니다.
- 여러 도구에서 생성된 결과를 하나의 시각화 환경으로 연결하는 파이프라인이 필요했습니다.

### 수행 내용

- PyroSim을 활용해 FDS 기반 화재 시뮬레이션 구성을 정리했습니다.
- 건물 도면과 공간 정보를 시각화 환경에 맞게 변환했습니다.
- 시뮬레이션 결과와 좌표 데이터를 Unreal 환경에 연결할 수 있도록 전처리 흐름을 구성했습니다.
- 서로 다른 프로그램에서 생성된 결과를 하나의 장면에서 사용할 수 있도록 데이터 연동 구조를 정리했습니다.

![시뮬레이션 연동 구성](/images/notion8.png)

### 결과

- 화재, 연기, 공간 정보를 반영한 대피 시각화를 구현했습니다.
- 서로 다른 도구에서 생성된 결과를 하나의 3차원 환경으로 연결하는 파이프라인을 구축했습니다.
- 시뮬레이션 결과를 해석하고 확인하기 쉬운 형태로 시각화할 수 있었습니다.

### 의미

이 프로젝트는 단순히 장면을 만드는 데서 끝나지 않고, 여러 도구의 결과를 연결해 검토 가능한 시각화 환경으로 정리한 경험이라는 점에 의미가 있습니다.  
시뮬레이션 결과를 실제 활용 가능한 형태로 연결하는 데이터 연동 역량을 보여줄 수 있는 프로젝트입니다.
