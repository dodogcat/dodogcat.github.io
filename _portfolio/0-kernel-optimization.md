**기간**: 2024.03 - 현재  
**역할**: GPU 커널 구현, 병목 분석, 성능 최적화  
**기술 스택**: Taichi (CUDA Backend), Python, MPM  
**코드**: 비공개 저장소, 요청 시 설명 가능

### 개요

Taichi 기반 MPM 시뮬레이션에서 병목이 되는 커널을 분석하고, 연산 구조와 메모리 접근 방식을 조정해 **커널 실행 속도를 13% 개선**한 프로젝트입니다.

### 문제

- P2G, G2P 단계에서 메모리 접근과 atomic 연산이 많이 발생해 커널 실행 시간이 길어졌습니다.
- 동일한 계산이 반복되면서 warp 단위 효율이 떨어지고 있었습니다.

### 수행 내용

- atomic 연산 횟수를 줄여 병목 구간의 연산 부담을 낮췄습니다.
- 커널을 분리해서 처리하던 흐름을 조정해 실행 오버헤드를 줄였습니다.
- SVD 계산 결과를 재사용해 중복 계산을 줄였습니다.
- P2G, G2P 단계의 메모리 접근 구조를 점검해 병목 원인을 분리했습니다.

### 결과

- 평균 커널 실행 속도를 **13% 개선**했습니다.
- atomic 연산이 집중되던 구간의 부담을 완화했습니다.
- 병목 구간을 정량적으로 확인하고, 이후 최적화 방향을 정리할 수 있는 기반을 만들었습니다.

### 의미

이 프로젝트는 단순 구현이 아니라, 수치 시뮬레이션 커널을 실제로 계측하고 병목을 줄이는 방향으로 개선한 경험이라는 점에 의미가 있습니다.  
추가적으로는 매 프레임 저장 데이터를 비동기 방식으로 분리하거나, 여러 프레임을 묶어서 저장해 I/O 오버헤드를 줄이는 방향을 검토하고 있습니다.
