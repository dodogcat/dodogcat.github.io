*VR 환경에서 분리수거 상호작용을 구현한 화면*

### 개요

VR 환경에서 분리수거를 연습할 수 있도록 만든 프로젝트입니다. 언어에 익숙하지 않은 사용자도 시각적 상호작용을 통해 분리수거 절차를 익힐 수 있도록 구성했습니다.

### 문제

- Unreal 환경에서 VR 입력과 상호작용을 안정적으로 연결할 필요가 있었습니다.
- Meta SDK와 OpenXR 사이의 호환 이슈를 정리해야 했습니다.
- 버튼 입력과 객체 조작을 자연스럽게 연결하는 상호작용 흐름이 필요했습니다.

### 수행 내용

- Meta SDK 기반 기능과 OpenXR 환경을 함께 검토하며 호환 문제를 확인했습니다.
- 버튼 입력을 받아 상호작용으로 연결하는 스크립트를 작성했습니다.
- VR 환경에서 사용자가 분리수거 대상을 집고 놓는 흐름을 구현했습니다.

### 결과

- VR 환경에서 동작하는 분리수거 학습 프로토타입을 구현했습니다.
- 입력 처리와 상호작용 연결 과정에서 발생하는 호환 이슈를 정리했습니다.
- VR 프로젝트에서 사용자 행동을 기준으로 인터랙션을 설계하고 구현한 경험을 쌓았습니다.

### 의미

이 프로젝트는 단순한 기능 구현보다, VR 환경에서 입력과 상호작용을 안정적으로 연결하는 흐름을 직접 다뤘다는 점에 의미가 있습니다. 이후 다른 프로젝트에서도 사용자 입력과 시스템 반응을 구조적으로 연결하는 경험의 기반이 됐습니다.
